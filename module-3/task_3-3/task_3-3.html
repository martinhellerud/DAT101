1. What is the difference between invoking and creating a function?

    2. Å lage en funksjon er når man skriver function og bestemmer hva den skal gjøre. Å kalle den er når man faktisk bruker den, f.eks. printTodaysDate(). Den gjør ingenting før man kaller den.

  2. Explain the syntax regarding semicolons and code blocks.

    3. Kodeblokken er alt som står mellom { og }. Man setter semikolon etter vanlige linjer med kode, men ikke etter } når man lager en funksjon.

  3. What happens when we try to store values from a function when it doesn't return any?

    4. Da blir verdien undefined, siden funksjonen ikke gir noe tilbake.

  4. How do we separate parameters from each other when creating a function?

    5. Med komma, f.eks. function convertTemperature(temperature, temperatureType).

  5. Explain how parameter names are related during the invocation and creation of a function.

    6. Det er rekkefølgen som bestemmer. Den første verdien man sender inn havner i den første parameteren osv. Navnene trenger ikke være de samme som variablene man sender inn.

  6. Explain why a parameter is undefined when a function call is missing a parameter.

    7. Hvis man ikke sender inn noe for en parameter, har den ikke fått noen verdi, så den blir undefined. Brukte det i Part 7 for å finne ut hva som manglet.

  7. Explain what happens when we use recursive functions.

    8. Funksjonen kaller seg selv igjen og igjen til den kommer til et punkt der den stopper, som i Part 10 når tallet blir 1. Uten et sånt stoppunkt ville den aldri stoppet.
